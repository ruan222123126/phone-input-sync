# phone-input-sync

把手边的手机变成电脑的输入设备：手机浏览器打开一个网页就能打字、语音输入、远程按键和当触控鼠标，文字直接落到电脑当前（或指定）的输入框里。

适合这些场景：

- 电脑连着电视 / 投影，人在沙发上用手机输入。
- 用 Moonlight 之类的串流玩游戏时，需要临时往游戏聊天框、登录框里输入中文。
- 电脑没有中文输入法，或手边只有手机。

## 功能

- **文字同步**：手机输入 → 电脑剪贴板 → 自动 `Ctrl+V` 粘贴到焦点输入框。
- **窗口锁定**：锁定一个电脑窗口，之后发送会自动切回该窗口再输入，不怕焦点跑掉。
- **语音输入**：手机录音 → 电脑端本地 Whisper 转文字（可选，首次下载约 150MB 模型）。
- **重复文字清洗**：自动修复语音识别「越说越完整、逐字重复」的输入（默认关闭）。
- **远程按键 / 快捷键**：在手机上发 `enter`、`ctrl+s`、`w,f` 等按键或按键序列。
- **触控鼠标**：手机当触控板，支持移动、点击、两指滚动。
- **自动发送**：按下发送后自动回车，或识别到末尾关键词 / 暂停后自动发送。

## 运行要求

- **电脑端**：Windows 10 / 11（窗口锁定、语音、重复文字清洗都依赖 Windows）。文字与按键同步的核心功能在其它平台也能编译，但未做验证。
- **手机端**：任意带浏览器的手机，与电脑连**同一个 WiFi / 局域网**（不要用访客网络，不要用手机热点隔离）。
- 语音输入、触控鼠标需要 **HTTPS**（浏览器对麦克风 / 陀螺仪的限制）。

## 快速开始

### 方式一：下载现成的 exe（推荐）

1. 打开本项目的 [Releases](../../releases) 页面，下载最新版的 `phone-input-sync.exe`。
2. 双击运行。首次运行若 Windows 防火墙弹窗，请**允许**；
   如果没放行成功，右键 exe「以管理员身份运行」一次，程序会自动添加防火墙规则。
3. 窗口里会打印局域网地址，例如：

   ```text
   文字输入: http://192.168.1.100:8765
   语音/陀螺仪: https://192.168.1.100:8766
   ```

4. 手机用同一 WiFi 的浏览器打开上面的**文字输入**地址即可开始输入。
   需要语音或触控鼠标时，打开 **HTTPS** 那个地址（首次会提示信任自签证书，选择继续 / 信任即可）。

> 运行数据（语音模型、证书、录音、实例锁）都放在 exe 同目录，重复启动会直接复用。

### 方式二：从源码编译

需要 Rust 工具链（stable）。

```powershell
cd desktop
cargo build --release
# 产物：desktop\target\release\phone-input-sync-desktop.exe
```

或直接开发运行：

```powershell
cd desktop
cargo run --release
```

## 使用

1. 电脑端保持运行（关掉命令行窗口手机就连不上了）。
2. 在电脑上点一下要输入的目标输入框。
   - 想固定目标：点手机上的「**锁定电脑窗口**」，之后发送会自动切回该窗口；点「取消锁定」恢复跟随焦点。
3. 在手机上输入文字，点「**发送**」。
4. 需要时点麦克风语音输入、或在设置里配置快捷键、开启触控鼠标。

## 设置说明

点手机右上角的设置按钮，分为几个页签：

**通用设置**

- **发送后自动按 Enter**：发送文字后自动回车（适合聊天框）。
- **自动发送关键词**：输入内容以指定关键词结尾时，自动延时发送。
- **暂停自动发送**：停止输入若干秒后自动发送。
  - 「自动发送关键词」与「暂停自动发送」互斥，只会生效一个。

**语音设置**

- **开启语音输入**：首次开启会询问是否在电脑端下载约 150MB 的 Whisper 模型；之后完全离线本地转写。
- **重复文字清洗**：见下方专门说明，默认关闭。

**快捷键设置**

- 自定义快捷键，点击即向电脑发送按键，例如 `enter`、`ctrl+enter`、`alt+tab`。
- 多个按键用逗号分隔会按顺序执行；纯数字表示等待秒数，含中文的步骤会当作文字粘贴。
  例如 `w,1,f`（按 w、等 1 秒、按 f），`继续,enter`（粘贴「继续」再回车）。

## 重复文字清洗（电脑端）

语音识别（尤其是经 Moonlight 串流时）常把逐字累积的中间结果全部拼进输入框，例如：

```text
语语音语音输语音输入语音输入。语音输入。像语音输入。像这语音输入。……
像这样的重复输入的文字。语音输入，像这样的重复输入的文字。
```

在手机端「语音设置」里打开 **重复文字清洗**（默认关闭），电脑端就会持续监视**当前焦点输入框**的文字。
停笔约 2 秒（可在设置里改）后，如果识别到这种「越说越完整的重复」，就自动把整段替换成最后那一整段，
例如上面的文字会被洗成：

```text
语音输入，像这样的重复输入的文字。
```

实现方式：电脑端用 Windows UI Automation 轮询焦点元素读取文字；写回时**聚焦该输入框、全选、再真实粘贴**
（而不是用 UIA 的 `set_value`）。这样对 WebView2 / Electron / 浏览器里的受控输入框（例如 OpenCode 桌面客户端）
才有效——`set_value` 只改画面、不改组件内部状态，发送时会回滚成原文；真实粘贴才会同步内部状态，并把光标留在文字末尾。

因此它只对支持 Windows 无障碍的输入框有效（记事本、多数聊天 / 浏览器输入框、OpenCode 桌面客户端等）；
密码框不会读取。若输入框不支持写回（只读），程序会保持只读、不做修改。该功能默认关闭，需要时再开。

**终端 / 命令行不在清洗范围内。** 终端（Windows Terminal、conhost）以及其中的 shell（PowerShell、cmd、WSL 等）
会把自己的屏幕内容暴露成可编辑的 UIA 文本，如果对它做清洗，就会替换掉正在运行的命令行和输出。
程序会按焦点元素所属进程的镜像名跳过这些目标，手机端探测到时也会显示「终端 / 命令行已跳过清洗」。
终端里的输入请用其它输入框完成。

## API

电脑端 HTTP 服务默认端口 `8765`，HTTPS（语音 / 陀螺仪）默认端口 `8766`。

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/sync` | `{ "text": "..." }` 同步到电脑焦点 |
| POST | `/api/key` | `{ "key": "ctrl+s" }` 或在焦点粘贴中文文本 |
| POST | `/api/mouse/move` | `{ "dx": 10, "dy": 0 }` 相对移动鼠标 |
| POST | `/api/mouse/click` | `{ "button": "left" }` 点击鼠标 |
| POST | `/api/mouse/scroll` | `{ "dx": 0, "dy": -3 }` 滚动 |
| POST | `/api/stt` | 原始 WAV 音频，电脑端转写为文字 |
| GET  | `/api/stt/status` | 语音模型是否就绪 |
| POST | `/api/stt/prepare` | 下载 / 准备语音模型 |
| POST | `/api/lock` / `/api/unlock` | 锁定 / 解锁目标窗口（Windows） |
| GET  | `/api/lock/status` | 目标窗口锁定状态 |
| GET  | `/api/repeat-watch` | 重复文字清洗状态，并探测当前焦点输入框 |
| POST | `/api/repeat-watch` | `{ "enabled": true, "pause_ms": 2000 }` 开关重复文字清洗 |
| GET  | `/api/status` | 服务状态与局域网 IP |
| GET  | `/api/health` | 健康检查 |

## 项目结构

```text
phone-input-sync/
├── desktop/            # 电脑端 Rust 服务（HTTP/HTTPS、粘贴、语音、窗口锁定）
│   └── src/
│       ├── main.rs          # 服务与 API
│       ├── repeat_watch.rs  # 焦点输入框监视（Windows UI Automation）
│       └── repetition.rs    # 「逐字累积重复」的检测与清洗算法
├── mobile/             # 手机端网页（单文件 index.html，由电脑端内嵌托管）
└── README.md
```

手机端目前是**单页网页**，不是原生 App；可「添加到主屏幕」当快捷方式使用。
后续如要打包成 Android APK，可在 `mobile/` 基础上用 Capacitor 或 WebView 壳封装。

## 常见问题

- **手机打不开电脑地址**：确认同一 WiFi（非访客网络）；确认电脑防火墙已放行（右键 exe 以管理员身份运行一次）；确认电脑端窗口还在运行。
- **发给了别人的电脑地址**：应该用**对方电脑窗口里打印的地址**在手机打开，而不是你电脑上的地址。
- **粘贴没反应**：发送前先在电脑上点好目标输入框；或使用「锁定电脑窗口」。
- **语音 / 触控鼠标用不了**：需要打开 **HTTPS** 地址（`:8766`）并在浏览器里信任自签证书。
- **提示「已在运行」**：程序是单实例的。请到任务栏找黑色命令行窗口，或在任务管理器里结束 `phone-input-sync.exe` 后重试。
