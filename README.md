# phone-input-sync

手机与电脑局域网输入同步：手机端一个输入框 + 发送按钮，电脑端运行服务后，把文字粘贴到当前焦点输入框。

## 原理

1. 电脑端启动 HTTP 服务（默认端口 `8765`），同时托管手机页面。
2. 手机浏览器打开 `http://<电脑局域网IP>:8765`。
3. 先在电脑上点击目标输入框，再在手机上输入并点「发送」。
4. 电脑端收到文字 → 写入剪贴板 → 模拟 `Ctrl+V` 粘贴到当前焦点。

```
phone-input-sync/
├── desktop/     # 电脑端 Rust 服务
├── mobile/      # 手机端网页（输入框 + 发送按钮）

```

## 电脑端运行

需要 Rust 工具链。在项目根目录执行：

```powershell
cd desktop
cargo run --release
```

启动后会打印局域网地址，例如：

```text
http://192.168.1.100:8765
```

手机用同一 WiFi 下的浏览器打开该地址即可。

## 手机端

当前版本是**极简网页**，不是原生 App 安装包：

- 点输入框会弹出手机输入法
- 点麦克风可语音输入（需先在设置中开启「语音输入」；首次会询问是否下载约 150MB 模型）
- 点「发送」同步到电脑
- 可「添加到主屏幕」当快捷方式使用

语音相关与运行数据都保存在电脑端 exe 同目录：`whisper\`（模型）、`certs\`（证书）、`stt\`（临时录音）、`instance.lock`。若这些文件已存在，程序会直接复用，不会重复下载或重建。

后续如需打包成 Android APK，可在 `mobile/` 基础上用 Capacitor 或 WebView 壳封装。

## API

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/sync` | `{ "text": "..." }` 同步到电脑焦点 |
| POST | `/api/stt` | 原始 WAV 音频，电脑端转写为文字 |
| POST | `/api/lock` / `/api/unlock` | 锁定 / 解锁目标窗口（Windows） |
| GET  | `/api/lock/status` | 目标窗口锁定状态 |
| GET  | `/api/repeat-watch` | 重复文字清洗状态，并探测当前焦点输入框 |
| POST | `/api/repeat-watch` | `{ "enabled": true, "pause_ms": 2000 }` 开关重复文字清洗 |
| GET  | `/api/status` | 服务状态与局域网 IP |
| GET  | `/api/health` | 健康检查 |

## 重复文字清洗（电脑端）

语音识别（尤其是经 Moonlight 串流时）经常把逐字累积的中间结果全部拼进输入框，例如：

```text
语语音语音输语音输入语音输入。语音输入。像语音输入。像这语音输入。……
像这样的重复输入的文字。语音输入，像这样的重复输入的文字。
```

在手机端「语音设置」里打开 **重复文字清洗**（默认关闭），电脑端就会持续监视**当前焦点输入框**的
文字。停笔约 2 秒（可在设置里改）后，如果识别到这种「越说越完整的重复」，就自动把整段替换成
最后那一整段，例如上面的文字会被洗成：

```text
语音输入，像这样的重复输入的文字。
```

实现方式：电脑端用 Windows UI Automation 轮询焦点元素读取文字；写回时**聚焦该输入框、
全选、再真实粘贴**（而不是用 UIA 的 `set_value`）。这样对 WebView2 / Electron / 浏览器里的
受控输入框（例如 **OpenCode 桌面客户端**）才有效——`set_value` 只改画面、不改组件内部状态，
发送时会回滚成原文，真实粘贴才会同步内部状态，并把光标留在文字末尾。

因此它只对支持 Windows 无障碍的输入框有效（记事本、多数聊天/浏览器输入框、OpenCode 桌面
客户端等）；密码框不会读取。若输入框不支持写回（只读），程序会保持只读、不做修改。
该功能默认关闭，需要时再开。

**终端/命令行不在清洗范围内。** 终端（Windows Terminal、conhost）、以及其中的 shell
（PowerShell、cmd、WSL 等）会把自己的屏幕内容暴露成可编辑的 UIA 文本，如果对它做清洗，
就会替换掉正在运行的命令行和输出。程序会按焦点元素所属进程的镜像名跳过这些目标，手机端
探测到时也会显示「终端/命令行已跳过清洗」。终端里的输入请用其它输入框完成。

## 注意

- 电脑端需保持运行；手机与电脑须连**同一 WiFi**（不要用访客网络 / 手机热点隔离）。
- 首次运行若提示防火墙，请允许；或右键 exe「以管理员身份运行」一次，程序会自动放行入站。
- 粘贴依赖当前窗口有焦点；发送前请确认电脑上的目标输入框已被点击。
- 首次使用建议在记事本里试一次，确认同步正常。
- 发给别人的是电脑端 exe：对方在自己电脑上运行后，用**对方电脑窗口里打印的局域网地址**在手机打开，不是用你电脑上的地址。
